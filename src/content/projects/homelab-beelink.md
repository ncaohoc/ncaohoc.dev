## Phần cứng

- Beelink ME mini, CPU Intel N200
- Hệ điều hành trên NVMe 250GB, dữ liệu trên NVMe 2TB
- Một số HDD 2.5" cho dữ liệu ít truy cập

## Phần mềm

- Ubuntu Server, quản trị qua SSH
- Các dịch vụ chạy trong Docker
- Chia sẻ file bằng Samba

## Mục tiêu tiếp theo

- Chạy server thử nghiệm cho game
- Cân nhắc tách router ra một máy riêng
